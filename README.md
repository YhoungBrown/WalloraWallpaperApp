# Welcome to your Expo managed Wallora Wallpaper Application 👋

#Instructions to run locally

To run this code locally, clone this repo, open project in your prefered IDE , in terminal, run npm install to install all dependencies required for the app to successfully run, then npm start to run the app locally, and Note: this is an expo managed codebase so you will need expo Go app to run the app on your physical device or emulator
